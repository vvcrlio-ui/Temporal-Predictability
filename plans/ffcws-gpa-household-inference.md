## 技术方案

### H1. 两级聚合（顺序不得颠倒）

E5b 锁定：**先对每户的 16 个损失取平均，再 bootstrap 家庭。**

```
loss[i] = mean over the 16 (seed, draw) reps of (y_true[i] - y_pred[i])**2
```

得到每档一个长度 886 的向量。**不得**把 886×16 行直接当作 14,176 个独立观测——
重复与家庭是两个层级。

### H2. 家庭配对 bootstrap

对家庭下标重抽（有放回，size = 家庭数），**同一组重抽下标同时应用到所有 landmark**
（这就是"配对"；分开抽会丢掉档间相关性，把差值的区间放大约 2 倍，实测见验收）。

每次重抽内：

```
R_t^(b) = mean_i∈b( loss_t[i] )  /  var_i∈b( y_true[i], ddof=1 )
```

⚠️ **分母必须在重抽内重算**（E5b 明文要求，"分母也是随机量，不得当常数"）。
把 `Var(Y_test)` 当常数会低估水平值的区间——实测分母自身的 bootstrap 标准差
约 0.0196，与分子同量级。

`ddof` 由参数传入，默认 1；点估计与 bootstrap 必须用同一个 `ddof`。

区间取百分位法（percentile），分位数可配，默认 2.5 / 97.5。
`B` 可配，默认 10000。随机数用显式传入的 `numpy.random.Generator` 或 seed，
**不得**使用全局 `np.random`。

### H3. 输出的量

对每个 landmark：`R_t` 点估计、bootstrap 区间、bootstrap SE。
对指定的对比（默认 `t=0` vs `t=9`，可配）：差值点估计、区间、SE、
`P(bootstrap draw <= 0)`。

⚠️ `P(draw <= 0)` **只能作为 bootstrap 分布的描述性汇总输出**，
列名用 `boot_share_le_zero`，**不得**命名为 `p_value` 或 `significance`——
按 E3b，这个差值不是 Bayes 不可预测性降幅的界，给它一个假设检验的名字会直接
诱导出被禁止的表述。

### H4. 必须同时产出的诊断

1. **重复层级的蒙特卡洛噪声**：各档 16 次重复的 `R` 的标准差与均值标准误。
   用于证明 H1 的"先平均"没有丢掉重要的不确定性。
2. **配对 vs 不配对的区间宽度比**：证明配对确实起作用。
3. **影响力检查**：依次剔除 |Δloss| 最大的 1 / 5 / 10 / 20 户后重算差值。
4. **过滤统计**：沿用 §C0 的口径（调用方传入规则，返回排除行数与占比）。

### H5. 描述性异质性（E5b 允许，但必须标为描述性）

按 `Δ[i] = loss_0[i] − loss_9[i]` 输出：改善户数占比、按真值分位的分组均值、
以及**总量分解**（改善户的增益之和、恶化户的损失之和、二者的净值）。

⚠️ 不得输出"前 X% 贡献了百分之多少的改善"这类**比例**统计量：净值是两股大流量
相抵后的小残差（实测 +61.89 与 −44.74 相抵得 +17.15），任何以净值作分母的份额
都会超过 100% 且不稳定。**只报绝对量，不报以净值为分母的份额。**

## 验收标准

以下点估计为**确定性**的，Codex 的实现必须**精确复现**（相对误差 < 1e-9）。
它们由本轮 pilot 导出独立算得，可作为回归基准。

**1. 主结果**（`super_learner`，N=1165，各档全量 K，`Var` 用 `ddof=1`）：

| t | K | `R_SL(t)` |
|---|---|---|
| 0 | 351 | 0.8871 |
| 1 | 848 | 0.8943 |
| 3 | 1701 | 0.8922 |
| 5 | 2506 | 0.8865 |
| 9 | 3397 | 0.8413 |

分母 `Var(Y_test)` = 0.422834（886 户，`ddof=1`）。

**2. 主对比**：`R_SL(0) − R_SL(9)` = **+0.0458**（4.58 个百分点）。

**3. 区间**（B=10000，percentile，家庭配对）：主对比 95% 区间约
**[+0.018, +0.073]**，bootstrap SE 约 **0.014**。
区间端点允许蒙特卡洛容差 ±0.003；SE 允许 ±0.001。

**4. 配对确实生效**：不配对（两档独立重抽）算得的差值 SE 约 0.030，
为配对的约 2.1 倍。实现须能同时给出两者。

**5. 分母重算确实生效**：把分母固定为常数重跑，各档**水平值**的区间宽度须明显
变窄（分母 bootstrap SD ≈ 0.0196）。实现须提供该对照开关以证明差异。

**6. 与聚合 CSV 一致**：由 `y_true`/`y_pred` 重算的每个 (model, N, K, seed, draw)
的 MSE，与主输出 CSV 的 `rmse**2` 相对偏差 < 1e-9。**已实测最大 4.66e-16。**

**7. 蒙特卡洛噪声可忽略**：各档 16 次重复的 `R` 的标准差实测 0.0026–0.0045，
均值标准误 0.0006–0.0011，比家庭 bootstrap SE（≈0.020）小约 20 倍。
实现须输出该对比。

**8. 命名约束**：输出表中不得出现 `p_value`、`significant`、`lower_bound`
（对差值而言）这三类列名。可用 grep 断言。

## 测试要求

全部 `@pytest.mark.parametrize`，合成数据，不依赖真实形状：

1. **两级聚合顺序**：构造重复间方差极大、家庭间方差极小的合成数据，断言
   "先平均重复再 bootstrap" 与 "把所有行当独立观测" 给出**显著不同**的区间宽度，
   且实现取的是前者。
2. **配对性**：构造两组强正相关的损失，断言配对 bootstrap 的差值方差
   **严格小于**独立重抽的差值方差；再构造独立的两组，断言二者接近。
3. **分母是随机量**：构造 `y_true` 方差大的合成数据，断言"重算分母"与
   "固定分母"给出不同的水平值区间；断言默认走重算分支。
4. **点估计可还原**：给定手工可算的小例子（如 4 户 × 2 重复），断言 `R` 与
   手算值一致。
5. **`row_id` 非位置索引**：构造 `row_id` 稀疏且不从 0 起的输入，断言结果与
   把它重编号为 0…n−1 后一致（即实现没有依赖取值本身），并断言按位置 join
   的错误实现会被测试抓到。
6. **退化输入**：单户、损失全相同、含 NaN、某档缺少部分家庭——应给出明确错误
   或有记录的跳过，**不得静默返回**。特别是"某档缺家庭"必须报错，
   因为配对 bootstrap 要求各档家庭集合相同。
7. **真实数据回归检查**（缺私有数据时带理由 skip）：断言验收标准 1 与 2 的
   点估计，容差 1e-9。

从 `project/` 跑 `../.venv/bin/python -m pytest -q`，通过数不低于当前基线
44 加本方案新增数。

## 已完成的验证（Claude，2026-08-13，只读核验，无需重做）

1. **导出完整性通过**：五档各 56,704 行 = 4 白名单格 × 16 重复 × 886 户；
   每个 (格, 重复) 恰好覆盖全部 886 个 `row_id`；无 NaN、无重复键；
   白名单与 `panels.landmark.pilot.yaml` 的 `prediction_export_cells` 完全一致。
2. **`row_id` = `challengeID`**：与 `test.csv` 中 `gpa` 非空的 886 个
   `challengeID` 集合完全相等；`y_true` 与 `test.csv` 的 `gpa` 逐户一致
   （最大差 0.0）。**不是位置索引**（`test.csv` 有 1591 行）。
3. **MSE 一致性通过**：五档最大相对偏差 4.66e-16（中位数约 1.45e-16）。
4. **验收标准 8 不成立，但诊断不是算错**：`R_SL(9) = 0.8413` 超过主方案设定的
   0.8 阈值。已排除"训练数据不足"这一解释——`N=1165` 就是 `train.csv` 中
   `gpa` 非空的**全部**行数（1165 / 2121），没有留验证集，与 E5b 一致。
   因此这不是算错，而是**本 demo 的流水线弱于 FFC 已发表的最佳模型**
   （我们的 `R²` ≈ 0.16）。其直接后果必须写进报告：
   **t=9 处的水平值是一个比已发表结果更松的上界，本身不构成新信息；
   本 demo 的贡献在于 t 的变化，不在 t=9 的水平。**
   该阈值原本是为"外推得到的渐近线"设的，外推已降级，标准需随之改写。
